# Release 2.1C — UX audit

این بازبینی روی قالب‌ها، CSS، مسیرهای Django و تست‌های محلی انجام شد. مرورگر تعاملی/ابزار screenshot در محیط اجرا موجود نبود؛ بنابراین نتیجهٔ بصری در عرض‌های ۱۴۴۰، ۱۰۲۴، ۷۶۸ و ۳۹۰ پیکسل و آزمون واقعی صفحه‌کلید **تأیید نشده** است.

| سطح | سلسله‌مراتب و اقدام | حالت خالی/بازخورد و دسترسی |
|---|---|---|
| ورود | نام و لوگوی سامانه، فرم فشرده، نمایش رمز | خطای ورود و محدودیت تلاش؛ برچسب‌های فیلد |
| مرکز خدمات و صفحهٔ اداره | جست‌وجو، کارت اداره، خانواده و خدمت، زمان‌بندی | نتیجهٔ خالی و لینک بازگشت؛ کد و نام کنار هم |
| جزئیات خدمت | شرح، ورودی، خروجی و زمان‌بندی؛ اقدام ثبت متناسب با محتوا | خدمت غیرفعال بدون لینک ایجاد درخواست |
| فرم درخواست | زمینهٔ اداره/خانواده/خدمت، بخش پایه و پویا؛ انصراف/پیش‌نویس/ثبت | خطای درون‌فیلد، انتخاب تاریخ شمسی، پیش‌نمایش و حذف فایل؛ محافظ ارسال دوباره |
| درخواست‌های من و اعلان‌ها | جدول فشرده، فیلتر، صفحه‌بندی؛ اعلان خوانده/نخوانده | حالت خالی، زمان و وضعیت متنی |
| جزئیات و مسیر درخواست | خلاصه، گفت‌وگو، فایل، زمان‌بندی، مرحله و تاریخچه | جداسازی یادداشت داخلی در سمت سرور؛ کنترل دسترسی دانلود |
| داشبورد و صف عملیاتی | شاخص، جدول، فیلتر چندوجهی، صفحه‌بندی با حفظ query | ردیف خالی و وضعیت متنی؛ محدودسازی در query سمت سرور |
| مدیریت درخواست و اداره | اقدام‌های مجاز، اعضا، کاتالوگ، انتشار؛ پنجرهٔ تأیید بایگانی | فرم جدا برای تغییرات؛ نقش‌های فقط خواندنی فاقد اقدام نوشتن |
| تنظیم ظاهر | فرم مدیر ارشد و پیش‌نمایش همان صفحه؛ بازگردانی پیش‌فرض | اعتبارسنجی رنگ/قلم/PNG در سرور؛ ذخیره همراه بازخورد |

قواعد responsive برای ناوبری در ۷۸۰ پیکسل، ستون‌های جزئیات، فرم و جدول‌های دارای اسکرول افقی بررسی شدند. focus-visible، reduced-motion، label، landmark، `aria-current`، status text و دیالوگ بومی در کد موجودند. اعتبار این موارد در مرورگر واقعی و با صفحه‌خوان هنوز باید بررسی شود. ابزار تحلیل استاتیک رابط هیچ finding قطعی ثبت نکرد؛ detector دیگر به دلیل عدم تفسیر `{% static %}` هشدارهای عمومی تولید کرد و مبنای تأیید بصری قرار نگرفت.

کنترل‌های backend و ساختار HTML با ۶۰ تست، از جمله مالکیت درخواست، محدودهٔ اداره، ناظر فقط‌خواندنی، یادداشت داخلی، فایل، وضعیت خدمت، فرم پویا، شناسه‌های تکراری و فرم‌های تودرتو اجرا شدند. نتیجهٔ این آزمون‌ها جایگزین مشاهدهٔ بصری یا آزمون عملی صفحه‌کلید نیست.
